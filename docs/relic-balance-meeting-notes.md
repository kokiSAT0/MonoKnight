# レリック能力調整 会議メモ

この資料は、テスターとの能力調整会議で通常遺物と呪い遺物を比較しやすくするための一覧です。
効果文、希少度、回数、呪い遺物の利点/代償は `Game/DungeonDefinition.swift` を正本にしています。

## 会議で見る観点

- 強すぎる候補: 取得した瞬間に以後の判断を単純化していないか。
- 弱すぎる候補: 条件が狭すぎて、拾っても体感しづらくないか。
- 上位互換: 同じ系統内で、低レアが完全に不要になっていないか。
- 階層依存: 序盤だけ強い、終盤だけ強い、または出現タイミングと噛み合っていない効果がないか。
- テスター確認: 数値の強弱だけでなく、「取りたい」「避けたい」「ビルドが変わった」と感じるか。

回数が `永続` のものは、その挑戦中ずっと効果が続きます。

| 底なしの背嚢 | 拾得カードの取得時使用回数が+5される。 | クリア後の報酬候補が1減る。最低2択。 | 報酬候補減少枠を主表から外す。 |
| 遺物狩りの焼印 | 手数上限の半分以内にクリアすると、クリア報酬のレリック出現率が5pt上がる。 | 新しく得るカードの使用回数が1減る。最低1回は残る。 | レリック率特化は通常遺物側へ寄せる。 |
| 灰の心臓 | 各フロア開始時にHPが2増える。 | クリア後の報酬候補が1減る。最低2択。 | 回復と候補減少の交換が地味なため新規出現なし。 |

## 出現と比較用メモ

- 通常遺物は通常宝箱、怪しい宝箱、クリア報酬から出る。床拾得には混ざらない。
- 通常宝箱の通常遺物抽選は、コモン75 / レア22 / レジェンド3。
- 怪しい宝箱・軽量の通常遺物は、コモン55 / レア35 / レジェンド10。
- 怪しい宝箱・深層の通常遺物は、コモン40 / レア42 / レジェンド18。
- クリア報酬のレリック枠は、通常時 コモン70 / レア25 / レジェンド5。
- 70%以内クリア時は 60 / 32 / 8、50%以内クリア時は 45 / 40 / 15 に寄る。
- 報酬品質系の通常遺物は、補助カード出現率を1効果につき+5pt、レリック出現率を1効果につき+2ptする。呪い遺物は各効果文のptだけ加算する。増えた分は移動カード出現率から引く。
- `曇った鏡` がある場合は、手早いクリアによるレリック品質補正が無効になる。
- 通常遺物と呪い遺物は、同じ挑戦中に重複して出ない。
