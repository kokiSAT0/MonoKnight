# MonoKnight ゲームルールハンドブック

本書は MonoKnight に実装されているゲームルールの詳細 Source of Truth とする。
プロダクト要件は [`product-spec.md`](product-spec.md) を併用し、旧仕様アーカイブの [`agents_legacy.md`](agents_legacy.md) は現行判断に使わない。
現行メインコンテンツは塔攻略のみであり、旧目的地制キャンペーン、Daily、ハイスコア、旧標準/クラシカル/Target Lab は現行仕様として扱わない。

## 1. 盤面・座標・初期配置

- 盤面は `BoardGeometry` が提供する N×N グリッド。塔フロアは `DungeonFloorDefinition` ごとの盤面サイズを使う。
- 基礎塔、成長塔、試練塔は原則 9×9 とする。
- 座標系は左下が原点 `(0,0)`。右方向が `+x`、上方向が `+y`。UI 表示では下段が y=0。
- 塔フロアの開始位置は `DungeonFloorDefinition.spawnPoint` で定義する。連続して次フロアへ進む場合は、基礎塔、成長塔、試練塔のすべてで前フロアの階段位置が次フロアの開始位置になる。
- 盤面の四角い枠は、このターンに実際に移動できるマスだけを示す。床落ちカード、危険範囲、撒菱、ひび割れ/崩落床は枠ではなく塗りや小マーカーで表現する。レイ型などの通過塗りが敵の危険範囲と重なる場合は、ダメージを示す赤塗りを優先し、終点の移動可能枠だけ残す。

## 2. カードと所持品

- 塔ダンジョン本編では通常の手札/NEXT/山札補充を使わず、基本移動と所持カードの回数制インベントリで進む。
- `DungeonFloorDefinition.cardPickups` のマスを踏むと、追加手数なしで移動/補助カードを取得する。拾得カードは1回使い切りで、クリア時に未使用分が残っていれば次フロアへそのまま持ち越す。床拾得には遺物を混ぜない。
- 成長塔の `DungeonFloorDefinition.relicPickups` の宝箱マスを踏むと、追加手数なしで遺物を取得する。遺物はカード枠とは別管理で、その挑戦中だけ効果が続く。同じ通常遺物/呪い遺物は1回の挑戦中に重複して出ない。怪しい宝箱の選択待ち中は一時的に選択オーバーレイを閉じて盤面を確認できる。取得結果は移動演出後に軽い詳細表示を挟み、確認タップで同じフロアの操作へ戻る。
- 床で拾ったカードとフロアクリア後に選んだカードはどちらも同じ所持カードとして扱い、残り使用回数を `DungeonRunState.rewardInventoryEntries` に保持して連続進行するフロア間で持ち越す。
- 所持カードは通常カード枠に保持し、補助カードも通常所持枠を1種類として数える。成長塔は初期5種類、スキル取得で最大9種類まで増える。基本移動が許可された塔では通常枠を消費しない基本移動カードとして別枠表示する。同じカードは種類枠を増やさず残り使用回数として積み、使用時は拾得分から先に消費する。
- 通常カード枠が満杯の状態で未所持の床落ちカードを踏んだ場合は、拾ったカードと所持中カードから捨てるカードを選ぶ。拾ったカードを選ぶと取得せず盤面から消し、所持カードを選ぶとその種類の残り回数をすべて捨てて拾ったカードを取得する。同種カードを踏んだ場合は選択を挟まず自動で回数を積む。この取捨選択では追加手数やペナルティは発生しない。選択待ち中は一時的に選択オーバーレイを閉じて盤面を確認できるが、選択を確定するまでは新しい移動やカード使用は行えない。
- 報酬は次フロアがあるクリア後に選ぶ。成長塔10Fは成長区切りだが通常報酬を選んで11Fへ進める。試練塔は無限進行のため毎階クリア後に報酬を選んで次階へ進める。新しい移動/補助カードを手札に追加するか、低確率の未所持遺物をカード枠なしで取得する。試練塔では低確率の手札拡張も同じ候補枠に並び、選ぶと通常カード枠を1つ増やす。クリア報酬は取らずに次階へ進んでもよく、その場合は所持カードと遺物だけをそのまま持ち越す。報酬候補が既に所持しているカードと同種だった場合は、種類枠を増やさず残り使用回数として積む。所持カードの整理は報酬を消費せず、報酬選択前に自由に行える。通常カード枠満杯で未所持カード報酬を取れない場合は、手札から不要な種類を外して空きを作るか、報酬を取らずに次階へ進める。移動/補助/遺物/手札拡張は同じ候補枠に並び、通常は最大3択にする。落下でクリア済み階へ戻って再クリアした場合、その階で最初に提示された候補のうち、まだ選んでいない候補だけを受け取れる。通常遺物と呪い遺物は候補数を増やさず、補助カード出現率やレリック出現率を少し高めることで報酬の質を上げる。報酬候補は名前、回数、希少度、効果確認導線を表示し、次階に対する性格ラベルやおすすめ表示は出さない。報酬候補は長押しで説明を確認でき、遺物候補は希少度に対応した色の枠線とバッジ、手札拡張は `枠+1` のバッジで表示する。試練塔の報酬候補は成長スキル補正を受けず、生成階数に応じた最大3択として扱う。報酬で遺物を選んだ場合は詳細表示を確認してから次フロアへ進む。
- 手札に追加した移動カードは通常2回使用可能にする。成長スキル「カード温存」取得後は対象の使用回数を3回にする。補助カードは1回報酬として扱い、カード温存の回数増加対象にしない。
- `補給` は移動せず1手使って自身を消費し、通常カード枠の現在上限まで埋まるように、現在の成長塔キャラクター用の塔用移動カードから未所持の移動カードをランダムに補給する。補給後はその場でターンが経過し、溶岩滞在ダメージと敵ターンが発生する。標準騎士では上下左右1マスカードを通常プールに出さず、上下左右1マスは基本移動だけが担当する。跳躍騎士ではナイト系カードの代わりに上下左右1マスカードを補給候補へ出す。上下/左右選択キングは廃止済み。補給で追加されたカードは現在フロア限りの1回カードで、クリア時に未使用分が残っていれば次フロアへそのまま持ち越す。
- 呪文系補助カード `消滅の呪文` は、手札で選んでから盤面上の通常敵を1体選び、移動せず1手使って自身を消費し、その敵だけを消滅させる。効果解決後はその場でターンが経過し、溶岩滞在ダメージと敵ターンが発生する。カード拾得は発生しない。通常敵がいないフロアでは使用できず、通常敵以外を選んだ場合は消費しない。
- 呪文系補助カード `全滅の呪文` は、移動せず1手使って自身を消費し、現在フロアの通常敵すべてを消滅させる。効果解決後はその場でターンが経過し、溶岩滞在ダメージと敵ターンが発生する。カード拾得は発生しない。通常敵がいないフロアでも空撃ちできる。
- 呪文系補助カード `凍結の呪文` は、移動せず1手使い、使用直後から合計3回分の敵ターンを止める。凍結中は危険範囲、着弾予告、次移動プレビューを表示せず、敵の攻撃範囲やメテオ予告に入ってもダメージを受けない。
- 呪文系補助カード `障壁の呪文` は、移動せず1手使い、使用直後から合計3回分の行動後処理でHPダメージだけを無効化する。敵、メテオ、撒菱、溶岩、毒、崩落穴のHPダメージは受けないが、敵の移動/回転/メテオ更新、危険範囲表示、床破壊、落下、足枷、手札喪失などの非HP効果は通常どおり発生する。
- 呪文系補助カード `ダークネスの呪文` は、移動せず1手使い、その階にいる間だけ見張りと回転見張りのレーザー攻撃を封じる。見張り系の射線危険と射線ダメージは消えるが、敵本体、回転見張りの回転、番兵/巡回兵/追跡兵/メテオ兵/星詠み兵、罠や床効果は通常どおり残る。見張り系がいない階や、すでにダークネス中の階では使えない。
- 見張りと回転見張りのレーザーは崩落穴で止まらず、穴マス自体と穴の先のマスも射線危険として扱う。岩/柱などの通常の通行不可マスや盤外では止まる。
- 呪文系補助カード `レール破壊の呪文` は、移動せず1手使い、その階にいる間だけ巡回兵のレール移動を封じる。巡回レールと次移動プレビューは消え、巡回兵は敵ターンで移動しないが、敵本体と隣接危険/攻撃は通常どおり残る。巡回兵がいない階や、すでにレール破壊中の階では使えない。
- 呪文系補助カード `フライの呪文` は、移動せず1手使い、その階にいる間だけ危険床系ギミックを無効化する。撒菱、衰弱罠、溶岩の踏み/滞在ダメージ、ひび割れ床の崩落化、崩落床の落下、毒、麻痺、足枷、幻惑、遺物破壊、手札喪失、沼、吹き飛ばしは発動しない。ワープ、カード温存、手札シャッフル、回復マス、カード/遺物拾得、鍵、出口、敵/メテオ/見張りなど床以外の危険は通常どおり残る。対象床がない階や、すでにフライ中の階では使えない。盤面表示では対象床を薄く残し、配置は読めるが今は効かない状態として示す。
- `万能薬` は、毒・足枷・幻惑・千鳥足状態のいずれかの時だけ移動せず1手使って自身を消費し、対象の状態を解除する。使用開始時に足枷中でも手数は1手分として数え、解除後の敵ターンは通常どおり最大1フェーズになる。手札喪失、レリック破壊、麻痺罠の即時休み、凍結の呪文、障壁の呪文は解除しない。旧セーブ内の `解毒薬` は、読み込み後に万能薬相当として扱う。
- 現行補助カードは `補給`、`消滅の呪文`、`全滅の呪文`、`凍結の呪文`、`障壁の呪文`、`ダークネスの呪文`、`レール破壊の呪文`、`フライの呪文`、`万能薬` とする。`NEXT更新`、`入替`、`導き`、`解毒薬` は退役カードとして扱い、塔攻略には出さない。
- `全域ワープ` と `固定ワープ` は退役カードとして扱う。ワープ要素は `TileEffect.warp` のワープ床として残し、カード報酬や床落ちカードには出さない。
- `DungeonRules.allowsBasicOrthogonalMove` が true のフロアでは、通常カード枠とは別の基本移動カードから基本移動できる。標準騎士の基本移動は上下左右1マス、跳躍騎士の基本移動はナイト8方向のジャンプとする。跳躍騎士の基本移動は途中マスを踏まず、着地点だけを踏破、敵撃破、罠/床、拾得、鍵/出口判定の対象にする。基本移動はカードを消費せず、手数を1増やし、敵ターン、床ギミック、出口判定、疲労判定の対象になる。ガイドモードがオンの場合は従来どおり盤面に表示された基本移動候補を直接タップできる。ガイドモードがオフの場合は、基本移動カードまたは通常カードを先に選び、表示された候補マスをタップして確定する。

## 3. クリア・失敗・処理順

- 各フロアは `GameMode.CompletionRule.dungeonExit(exitPoint:)` を使い、指定出口/階段マスへ到達するとクリアする。
- レイ型など途中マスも踏むカードでは、移動途中で解錠済みの出口/階段へ入った時点で移動を止めてクリアする。
- 有限塔の最終階をクリアした場合は、通常の次階報酬ではなく登頂リザルトを表示する。登頂リザルトでは到達階、塔累計手数、残HP、塔累計所要時間、所持通常遺物、所持呪い遺物を今回のランのまとめとして見せる。手札や次階報酬は表示しない。試練塔など次階が続く塔、途中階、失敗リザルトは従来の表示を使う。
- ダンジョン失敗条件は `DungeonFailureRule` で管理する。現行の基本失敗条件は HP 0 とする。手数上限は即失敗ではなく疲労開始ラインとして扱い、上限超過1手目、その後は超過4手目、7手目、10手目...で防御/障壁では防げない疲労ダメージを1受ける。残り手数が0になると、UIの手数ゲージ領域は3つの丸による疲労インジケーターへ切り替わり、安全な手数消費中ではないことを示す。
- レイ型や直線2/斜め2など途中マスも踏むカードでは、通過マスごとに `踏破 → 敵攻撃範囲ダメージ → 敵踏み潰し → 罠/床割れ → 拾得カード → 鍵/出口判定 → 麻痺罠` を処理し、表示もその順で一歩ずつ反映する。ワープ床や帰還ワープの着地点も同じ順序で処理し、着地点が敵攻撃範囲なら着地時点でダメージを受ける。手札満杯で拾得カードの取捨選択が必要になった場合はそのマスでいったん止め、1枚分の選択を確定してから残りの移動を続ける。HP 0、崩落穴への落下、出口到達で移動が止まる場合は、その先のマスは踏まない。沼、足枷罠、麻痺罠はレイ型などの連続移動を止めるが、直線2/斜め2のような固定距離カードは途中で止めず、効果だけを適用して本来の到達先まで進む。
- プレイヤー移動が止まった後の処理順は `出口判定 → 敵ターン → 疲労判定 → 失敗判定`。出口へ着いた手は、疲労や敵ターンより先にクリアとして扱う。麻痺罠で止まった場合は1回休みとして表示し、通常の敵ターンを最大2回連続で解決する。凍結の呪文が有効な敵ターンは、敵の移動、回転、攻撃、メテオ着弾を丸ごとスキップして残り凍結回数を1減らす。障壁の呪文が有効な行動後処理では、敵ターンや溶岩滞在処理を通常どおり解決したあと、HPダメージだけを0にして残り障壁回数を1減らす。疲労ダメージは障壁では防げない。
- 連続進行するフロア間では HP、所持カードの残り使用回数、成長塔と試練塔の所持遺物を引き継ぎ、手数、敵、床状態、床落ちカード配置は各フロア開始時にリセットする。試練塔ではラン中だけ HP、拾得/報酬カード、取得遺物、手札拡張による通常カード枠上限、累計手数を持ち越し、永続成長、開始カード、成長補正、持ち込み遺物は持ち込まない。
- 失敗時の再挑戦は、成長塔では現在の区間開始階、基礎塔と試練塔では1Fから始める。成長塔の復帰系スキルは再挑戦時だけ追加支給として効き、新規開始や通常の区間開始は強めない。試練塔は再挑戦ごとに新しい生成 seed の新規ランにする。

## 4. 塔の種類

- `DungeonLibrary.shared` は当面 `基礎塔`、`成長塔`、`試練塔` を提供する。
- 基礎塔はチュートリアル用の 9×9 / 6 フロア構成とし、出口到達、HP、手数、見張り、番兵、ひび割れ床、鍵、見える罠、ワープ床、レール巡回兵を順に確認する。成長塔はロックしないが、基礎塔未クリアで成長塔を初回開始する時だけ基礎塔を勧める。永続成長ポイント、スキルツリー効果の対象外にする。
- 成長塔は 9×9 / 50 フロアの `.growth` 本編塔とする。1-10F、11-20F、21-30F、31-40F、41-50F の5区間で構成し、10F/20F/30F/40Fクリア後は次区間から開始できる。開始時は標準騎士と跳躍騎士を選ぶ。標準騎士は常時選択可能、跳躍騎士は50Fクリア後に恒久解放する。開発者向け診断の「跳躍騎士を最初から使う」は通常の解放状態を変えず、未解放でも選択可能にする確認用設定とする。
- 成長塔では5F刻みの初回クリアで成長ポイントを各1得る。同じ区切りでは重複付与しない。
- 試練塔は 9×9 / 無限階の `.roguelike` 塔とし、永続成長ポイント、スキルツリー効果、開始カード、成長補正、持ち込み遺物、塔ごとの成長獲得表示の対象外にする。挑戦開始時に生成 seed を作り、seed と階数から各階を決定論的に生成する。同じ seed と同じ階数では中断復帰後も同じ配置になり、違う seed または階数では別配置になる。1-10Fは敵密度より罠、床割れ、拾得カード、seedで揺れる保証宝箱、手数制限を中心に後半へ向けたビルドを作る。2-4F、5-8F、9-12Fには各1個以上の宝箱寄り道を保証し、序盤の保証宝箱3個のうち少なくとも1個は軽量の怪しい宝箱にする。31F以降は4階に1回以上、51F以降は3階に1回以上の宝箱寄り道を保証し、通常ルート外の任意目標として狙うか諦めるかを選ばせる。51F以降は3階単位で準備/圧力/回収の役割を持たせ、罠寄り、敵圧、ワープ、暗闇、総合型の内部テーマで配置の偏りを変える。追跡兵は11F以降、メテオ兵は16F以降に出す。呪い遺物 `群れ呼びの護符` 所持中は、敵がいる階の敵数を置ける範囲まで2倍にする。階層表示は `試練塔 12F` のように分母なしで表示し、ローカル最高到達階を標準騎士/跳躍騎士別に保存する。
- タイトルの通常プレイ導線は塔選択だけを表示する。旧キャンペーン、Daily、ハイスコア、旧ランキング画面は通常導線に出さない。

## 5. 成長塔

- 成長塔は巡回、鍵、見える罠、ワープ床、敵警戒、回転見張り、追跡兵、メテオ兵、星詠み兵、暗闇、固定の岩/柱、床割れ、状態罠を段階的に複合する。1-10Fは学習区間、11-20Fは警告区間、21-30Fはスキル未取得プレイの壁として扱い、41F以降は星詠み兵を少量混ぜてその場待機にも圧をかける。敗北周回で危険回避、準備、復帰、報酬、索敵スキルを積むほど50F踏破が現実的になる難度にする。
- 暗闇フロアでは、プレイヤー現在地を含む周囲1マス、階段、鍵、見張り/回転見張り本体、見張り/回転見張りのレーザー危険マス、メテオ着弾予告マスを常時表示する。レイ型などの移動リプレイ中は、通過マスごとにその時点の現在地を基準に視界を更新する。番兵、巡回兵、追跡兵、メテオ兵、星詠み兵の本体、拾得カード、宝箱、罠、床効果、巡回レール、巡回/追跡の移動プレビューなどは視界内だけ表示し、判定や取得、被弾、敵行動は通常フロアと同じまま扱う。
- 岩/柱は1フロア2〜4個程度の固定障害物で、鍵を取っても消えない。
- 1-8Fは難しいギミックを足す代わりに拾得カードを各5枚前後へ増やし、拾うほど短縮、安全ルート、鍵やカード回収への寄り道が楽になる低難度区間として扱う。
- 成長塔ではラン開始時に `DungeonRunState.cardVariationSeed` を決め、同じラン中は固定したまま、拾得カードの種類/位置/数、敵初期位置/向き/巡回路、鍵位置、ワープ位置、階段接続、岩/柱、床ギミック、宝箱位置、クリア後報酬候補を階ごとに解決する。敵種、敵数、鍵の有無、ワープペア数、階テーマ、手数上限は固定テンプレートを維持する。見張り/回転見張りの初期向きは、盤外や岩/柱ですぐ止まる方向を避け、同じ位置から有効射線が最も長い方向へ寄せる。階段は区切り階を含めて近傍候補へ揺れ、前階の階段位置が次階の開始位置になる。拾得カード数は既存数を基準に -1 / 0 / +1 程度で揺れ、1-8F は4〜6枚、9F以降は最低3枚を保つ。11F以降は見えるヒビ床を含む撒菱、溶岩、床割れの圧を増やし、21F以降は毒、足枷、幻惑、手札喪失罠を階層帯ごとの目標密度まで追加する。31F以降は複合状態罠、41F以降は踏破区間として溶岩寄りの危険床、見えるヒビ床、状態罠を組み合わせる。撒菱は常に1ダメージで一度踏むと消え、溶岩は常に2ダメージで消えない。試練塔の生成深層では溶岩が2x2や2x3などの塊として出る場合がある。15F/25F/35F/45F は区間内の判断を確認する関門として、宝箱警戒、鍵/ワープ/追跡、暗闇/巡回/状態罠、呪い箱/崩落のテーマを強める。回復マスは21F以降の通常階から減らし、主に節目階の一度きりの立て直しとして残す。岩/柱は階層帯ごとの軽い増減に留め、鍵あり階では開始地点から鍵、鍵から階段まで基本移動だけの代表導線を残す。ワープは必須ルートではなく選択肢として扱い、ワープなしでも階段へ到達できる。カード種別は 1-5F、6-10F、11-15F、16-20F、21-30F、31-40F、41-50F の階層帯と床拾得/クリア報酬ごとの重み付きプールから抽選する。補助枠では万能薬を6F以降、ダークネスの呪文、レール破壊の呪文は11F以降、フライの呪文は危険床が増える21F以降に混ぜ、消滅の呪文と全滅の呪文は万能な通常回答ではなく希少な切り札として低重みに抑える。クリア報酬では次フロアが暗闇、見張り、巡回、状態罠、手札喪失、危険床、追跡/メテオ圧を含む場合、対応する補助カードを補助枠内で明確に優遇する。表示上は候補の順位付け、性格ラベル、おすすめ表示を行わない。床拾得は移動約90%/補助約10%/遺物0%。クリア報酬は通常時に移動約89%/補助約10%/遺物約1%で、クリア手数が有効手数上限の70%以下なら 77%/20%/3%、50%以下なら 65%/30%/5% へ寄せる。補助カード全体は移動カードを置き換える主役ではなく、次フロアの危険を読んだ時に効く報酬として扱う。報酬品質系の通常遺物は、補助カード出現率を1効果につき+5pt、レリック出現率を1効果につき+2ptし、呪い遺物は各効果文のptだけ加算する。増えた分は移動カード出現率から引く。同じ seed と同じクリア手数では同じ候補になる。
- 成長塔と試練塔で選んだ騎士は `DungeonRunState.movementStyle` に保存し、次階進行、中断復帰、落下復帰、失敗後の区間再挑戦で維持する。標準騎士の拾得/報酬/開始支度/補給候補は現行プールを使い、ナイト系カードも通常どおり出る。跳躍騎士の拾得/報酬/開始支度/補給候補ではナイト系カードを上下左右1マスカードへ置換する。試練塔の跳躍騎士は成長塔50Fクリアまたは開発者設定の解放条件に従う。基礎塔は標準移動のままとする。
- 敵撃破報酬系の通常遺物は、その階で倒した敵1体につきクリア報酬の補助カード出現率+3ptまたはレリック出現率+1ptを加算し、増えた分は移動カード出現率から引く。撃破数には移動で踏んだ敵、`消滅の呪文`、`全滅の呪文` で消した敵を含め、次フロア開始時にリセットする。`討伐者の勲章` だけは取得後の撃破数をラン通算で保持し、10体ごとに未所持のコモン通常遺物を1つ自動取得する。
- 成長塔には数階に1個の宝箱を置く。通常宝箱は踏むと未所持通常遺物を即取得し、怪しい宝箱は移動演出後に実名表示の2択を出す。取得済み宝箱は同じラン中に盤面から消える。宝箱は spawn / exit / 鍵 / 敵 / 罠 / 岩柱 / ワープ / 拾得カードとは重ねない。21F以降の宝箱は通常ルートから少し外した任意目標を基本にし、HP、手札、呪い状況を見て狙うか諦めるかを選ばせる。後半の一部では、上階の崩落穴からだけ入れる小部屋に宝箱を置く。小部屋には `returnWarp` の帰還ワープを置き、桂馬・斜め移動・距離2移動などの跳躍着地では外側から入れず、宝箱取得後に通常エリアへ戻れる任意の寄り道報酬として扱う。通常宝箱で未所持通常遺物が尽きた場合や怪しい宝箱の2択が成立しない場合は重複付与せず、HP +1 の小補填だけ行って宝箱を消す。通常遺物、呪い遺物、補填結果はいずれも取得結果として詳細表示する。
- 通常遺物にはコモン、レア、レジェンドの希少度を持たせる。通常宝箱の通常遺物抽選は コモン75 / レア22 / レジェンド3、怪しい宝箱・軽量の通常遺物は コモン55 / レア35 / レジェンド10、怪しい宝箱・深層の通常遺物は コモン40 / レア42 / レジェンド18 にする。クリア報酬のレリック枠は通常時 コモン70 / レア25 / レジェンド5、70%以内クリアで 60 / 32 / 8、50%以内クリアで 45 / 40 / 15 に寄せる。`曇った鏡` がある場合は手早いクリアによる希少度補正を無効化する。
- 塔ラン中はプレイヤー向けのラン履歴を最大80件保持する。履歴には階層、手数、座標、ダメージ、回復、無効化、レリック/呪い取得を時系列で残し、敵やメテオの被弾は見張り、回転見張り、メテオ兵などの種類も本文に含める。プレイ中の履歴ボタンと失敗リザルトの「直近の履歴」から確認できる。床落ちカード取得などHPやビルド変化に直接関係しない通常イベントは初期実装では含めない。
- 宝箱は通常宝箱と怪しい宝箱に分ける。通常宝箱は通常遺物だけを出す。怪しい宝箱は盤面表示と VoiceOver 名を変え、軽量版・深層版ともに通常遺物と呪い遺物から選ぶ。深層版の通常遺物候補は高希少度が出やすい。12Fは軽量版、16F/19Fは深層版にする。
- 遺物と呪い遺物はゲームオーバー、区間開始からの再挑戦、新規開始、最終クリアで失われる。中断復帰では `DungeonRunResumeSnapshot` に所持遺物、所持呪い遺物、取得済み宝箱を保存して保持する。基礎塔には宝箱と遺物を入れない。試練塔には成長塔由来の宝箱とクリア報酬レリックを出すが、新規挑戦へは持ち込まない。
- 通常遺物は72種とする。追加遺物は `木彫りの護符`、`銅の砂時計`、`旅の保存食`、`遠星の杯`、`欠け星の杯`、`旅の水筒`、`月露の水筒`、`小さなランタン`、`鈍い針`、`継ぎ接ぎロープ`、`野戦医療箱`、`斥候の羅針盤`、`早業の鞘`、`清めの護符`、`清めの大護符`、`不死鳥の羽根`、`賢者の写本`、`火消しの札`、`耐火ランタン`、`見張り除けの面`、`レール止めの楔`、`レール守りの標識`、`追跡避けの煙玉`、`追跡封じの笛`、`星隠しの布`、`罠踏みの靴底`、`残り火の外套`、`見張りの単眼鏡`、`レール守りの護符`、`追跡避けの囮`、`解毒石`、`解毒の霊石`、`星除けの傘`、`守護者の外套`、`落下止めの錨`、`焚き火の熾火`、`商人の天秤`、`護りの小札`、`護りの札`、`霜の鈴`、`討伐の小袋`、`狩人の旗`、`威圧の角笛`、`討伐者の勲章`、`拾い火のレンズ`、`撒菱読みのレンズ`、`溶岩読みのレンズ`、`罠読みのレンズ`、`影読みのレンズ`、`逆巻きの砂時計`。通常遺物は直接的なマイナス効果を持たず、有限回数を持つものは残り回数を表示し、回数なしで挑戦中続くものには分類名を表示しない。通常宝箱、怪しい宝箱、クリア報酬では所持済み通常遺物を候補から除外する。
- `割れた盾` は次に受けるダメージを1回だけ1軽減する。
- `重い王冠` はクリア後に新しく得る移動報酬カードの使用回数を1増やす。
- `灯る心臓` は取得時に HP を2増やす。
- `黒い羽根` は落下そのものは止めず、次に受ける落下HP減少を1回だけ無効化する。
- `欠けた砂時計` は各フロアの手数上限を3増やす。
- `討伐の小袋` はその階で敵を1体倒すたび、クリア報酬の補助カード出現率 +3pt。`狩人の旗` はその階で敵を1体倒すたび、クリア報酬のレリック出現率 +1pt。`威圧の角笛` は敵を倒した行動後に敵が残っていれば敵ターンを1回停止する。`討伐者の勲章` は取得後、敵を10体倒すごとに未所持のコモンレリックを1つ得る。1行動で複数体倒しても敵ターン停止は1回だけ。
- `旅人の靴` は各フロアの手数上限 +1。`銀の針` は次の罠ダメージ、`火消しの札` は次の溶岩ダメージ、`古びたロープ` は次の落下HP減少、`見張り除けの面` は次の見張り・回転見張りダメージ、`レール止めの楔` は次の巡回兵ダメージ、`追跡避けの煙玉` は次の追跡兵ダメージ、`星隠しの布` は次のメテオ兵ダメージを1回だけ無効化する。`鈍い針`、`耐火ランタン`、`継ぎ接ぎロープ`、`守りの香炉`、`レール守りの標識`、`追跡封じの笛`、`守護者の大盾` は、対応する罠/溶岩/落下HP減少/見張り系/巡回兵/追跡兵/メテオ兵ダメージを各フロアで最初の1回だけ無効化する。`罠踏みの靴底`、`残り火の外套`、`落下止めの錨`、`見張りの単眼鏡`、`レール守りの護符`、`追跡避けの囮`、`星除けの傘` は、対応する罠/溶岩/落下HP減少/見張り系/巡回兵/追跡兵/メテオ兵ダメージを常に1軽減する。`守護者の外套` は敵とメテオから受けるHPダメージを1軽減し、同じダメージ源では他の軽減レリックと重複しない。`護りの小札` は各フロア開始時に1行動後処理分、`護りの札` は2行動後処理分の障壁を付与し、敵や床の非HP効果は通常どおり進めたままHPダメージだけを無効化する。`霜の鈴` は各フロア開始時に最初の敵ターンを1回停止する。`星の杯` は取得後から2フロアごとのフロア開始時 HP +1。`遠星の杯` は取得後から3フロアごとのフロア開始時 HP +1。`欠け星の杯` は取得後から5フロアごとのフロア開始時 HP +1。`探索者の袋` は拾得カードの取得時使用回数 +1。`月の鏡` は次に呪い遺物を得る時、1回だけ無効化して未所持の通常遺物に変える。`勝利の旗` はクリア報酬のレリック出現率 +2pt。`風切りの羽根` は旧効果のレリックで、現在は新しく出現せず使用回数補正も発生しない。`罠師の手袋` は罠でダメージまたは状態異常を受けた時、次のクリア報酬の補助カード出現率 +5pt。`拾い火のレンズ` は暗闇フロアで未取得の拾得カードが常に見える。`撒菱読みのレンズ` は暗闇フロアで撒菱が常に見える。`溶岩読みのレンズ` は暗闇フロアで溶岩が常に見える。`罠読みのレンズ` は暗闇フロアで隠し罠が常に見える。`影読みのレンズ` は暗闇フロアで全ての敵が常に見える。`予備のたいまつ` は暗闇フロアの視界を周囲2マスへ広げる。`双子の小袋` は新しく得る補助報酬カードの使用回数 +1。`勝負師のコイン` は手数上限の半分以内クリア時にクリア報酬のレリック出現率 +2pt。`王家の宝冠` はクリア報酬のレリック出現率 +2pt と新規報酬カード使用回数 +1。`不滅の心臓` は各フロア開始時 HP +1。`星詠みの砂時計` は各フロアの手数上限 +5。`木彫りの護符` は取得時 HP +1。`銅の砂時計` は手数上限 +2。`旅の保存食` は各フロア開始時 HP2以下なら HP +1。`旅の水筒` は次の3フロア開始時に HP +1。`月露の水筒` は次の5フロア開始時に HP +1。`小さなランタン` は暗闇視界を +1 し、視界半径は最大3。`野戦医療箱` は回復マスの回復量 +1。`斥候の羅針盤` は70%以内クリア時にクリア報酬の補助カード出現率 +5pt。`早業の鞘` は旧効果のレリックで、現在は新しく出現せず使用回数補正も発生しない。`清めの護符` は次の状態異常または手札喪失系を1回だけ無効化し、`清めの大護符` は2回まで無効化する。`不死鳥の羽根` は致死ダメージを1回だけ HP1 で耐える。`逆巻きの砂時計` はHPが0になる時に1回だけ過去のランダムな階層でHP1から復活する。`賢者の写本` は新規の拾得カード、移動報酬カード、補助報酬カードの使用回数 +1。`解毒石` は毒罠の毒ダメージ回数を1減らし最低1回にし、`解毒の霊石` は2減らして最低1回にする。`焚き火の熾火` は回復マスで毒・足枷・幻惑を解除する。`商人の天秤` はクリア報酬でレリックを選んだ時に次階開始HP +1。
- 呪い遺物は互換用定義を含めて45種を保持するが、新規出現は15種に絞る。怪しい宝箱では所持済み呪い遺物を候補から除外し、通常遺物に対して条件付きの強い利点と代償を選ばせる。新規出現する呪い遺物は、`追跡の匂い袋`（追跡兵がいる階の床拾得カード配置数 3倍 / 追跡兵ダメージ +1）、`火渡りの札`（溶岩を踏んだ階の補助カード出現率 +10pt / 溶岩滞在ダメージ +1）、`揺らぐ焚き火`（回復マス回復量 +3 / 回復マスで幻惑）、`細工師の工具箱`（所持中の移動/補助カードがクリア報酬に出やすい / 同じカードに寄りやすく新規種類を広げにくい）、`急行切符`（半分以内クリアで次階開始 HP +3 / 疲労ダメージ +1）、`千鳥の契約`（手札スロット +1、最大10枠 / 基本移動不可）、`赤い杯`（取得時 HP +8 / 以後受けるダメージ +1）、`歪んだ砂時計`（クリア報酬に補助カードが必ず1つ以上出現 / 半分超過クリア時に次階開始HP -1、最低1）、`契約の写本`（新規拾得カード、移動報酬カード、補助報酬カード使用回数 +3 / 手数上限 -5）、`王家の借用書`（補助カード出現率 +10pt、新規報酬カード使用回数 +2 / クリア報酬選択時に次階開始HP -2、最低1）、`背水の大盾`（各フロア最初のHPダメージ -3 / 手数上限 -4）、`補給係の鈴`（フロア開始時に空き手札枠へ補給 / 敵あり階を無討伐クリアすると次階開始HP -1、最低1）、`眠りの軍太鼓`（敵ターンが2ターンに1回 / 敵由来HPダメージ 3倍）、`群れ呼びの護符`（フロア開始時に3ターン分の障壁 / 解決済みフロアで敵数2倍、置ける範囲まで）、`黄金の封蝋`（レリック報酬と宝箱の通常遺物候補がレア以上 / 現在HP、回復、次階開始HPが2を超えない）とする。`罠寄せの磁石`、`毒見の小瓶`、`支援の誓約`、`呪われた王冠` は差し替え前の互換用として新規候補から外し、`油染みの靴`、`黒曜の心臓`、`欲深い袋`、`底なしの背嚢`、`遺物狩りの焼印`、`灰の心臓` と同じく既存ランや中断復帰で取得済みなら従来どおり効果・表示・保存を維持するが、新しい怪しい宝箱の候補には入れない。
- 成長塔では区切り階を含めて前フロアの階段位置を次フロアの開始位置にし、階段位置も複数パターンへ分散して周回時の固定感を減らす。
- 床割れは区切り階や最終階など、通常遷移できる次階がない階や、落下先の同座標が固定岩/柱などの `impassableTilePoints` になる場所には置かない。落下専用宝箱へつながる崩落床は、通常クリアに不要な任意リスクとして置き、落下先の小部屋は通常移動や跳躍着地では外側から入れず、帰還ワープで通常ルートへ戻せる配置にする。

## 6. 永続成長

- 成長ポイントは成長塔カード内の「成長」で使用し、準備、報酬、危険回避、索敵、復帰の分岐網型スキルツリーから取得する。表示はまず系統ごとの役割カードを並べ、選んだ系統を前提スキル順の段階チェーンで読む形にする。「全体」表示では5系統の段階ノード図も確認できる。詳細説明、取得、オン/オフは選択中スキルの詳細欄で扱う。
- 成長ポイントは成長塔の5F刻み初回クリアで各1得る。区間終端の10F/20F/30F/40F/50Fを再クリアした場合も周回報酬として各1得られ、周回すれば最終的に全スキルを取得できる。
- スキル取得条件はポイントと前提スキルの解放状態だけを見る。到達階層は成長ポイント獲得、区間開始解放、各効果の発動階層には使うが、スキル取得ロックには使わない。取得済みスキルはコストなしで個別にオン/オフでき、前提スキルをオフにしても、取得済みの後続スキルは単体で有効にできる。
- 区間開始時は、索敵や準備スキルで得た候補から「開始支度」を1つ選んで持ち込む。開始支度は成長塔の新規区間開始だけで選び、基礎塔、試練塔、通常の次階進行、中断復帰では選ばない。
- 準備系は基本の移動/補給支度を増やす。報酬系は候補補完、カード温存、4択化、補助/遺物候補の保証を扱いつつ、報酬傾向に合う支度を出しやすくする。危険回避系は罠・床崩落、敵、メテオへの対策支度を出しやすくする。索敵系は成長塔カード内の「次区間の見通し」に床/報酬/敵/経路の傾向を挑戦前表示し、同じ傾向から開始支度候補を増やす。復帰系は失敗後の再挑戦専用支援として、直前区間に合わせた補給/障壁/万能薬/経路/凍結支度を優先する。
- 一部の深層スキルは複数系統の取得済みスキルを前提にする。例として「深層補給術」は準備系と報酬系、「危険予報」は索敵系と危険回避系を前提にする。
- フロア間の HP 引き継ぎは通常どおり `DungeonRunState.carriedHP` を使い、永続成長で HP は増やさない。

## 7. 敵・床・ギミック

- 敵は `EnemyDefinition` で配置し、進行中は `EnemyState` として管理する。現行では番兵、巡回兵、見張り、回転見張り、追跡兵、メテオ兵、星詠み兵を扱う。敵の形は挙動、色は攻撃力を表す。攻撃力は通常1で、成長塔と試練塔では21F-40Fが2、41F以降が3になる。巡回兵は、初期地形で4マス以上の実移動可能な巡回路がある場合だけ配置し、往復込み6マス以上のレール巡回を基本にする。巡回路には直線/折れ線を戻る往復レールと、最後の点から先頭へ戻れるループレールがあり、ループレールでは複数の巡回兵が同じレールを同じ向きに回る場合がある。
- 敵本体の盤面マーカーは種類ごとに形を分ける。番兵は盾、巡回兵は巡回矢印、見張りは目、回転見張りは瞳孔部分の右回り/左回り矢印、追跡兵は追跡矢印、メテオ兵は落星印、星詠み兵は落星印に小さな標的印を重ねた形を使い、行動前にタイプを判別できるようにする。遊び方内の敵辞典にも同じ分類と読み方を載せる。
- 遊び方内の辞典は発見型にする。敵、マス、カード、レリック、呪い、イベントは、盤面、手札、床拾得、報酬候補、取得結果として表示された時点で発見済みにし、未発見項目は `？？？` として名称・見た目・効果を隠す。開発者向け診断メニューの全表示トグルがオンの場合だけ、発見状態に関係なく全詳細を見せる。
- 敵は種類を問わず、プレイヤーがそのマスを踏むと倒れる。レイ型、吹き飛ばし、ワープなどで通過したマスも対象になり、踏んだ敵はその手の敵ターンでは攻撃しない。
- 敵の危険範囲表示は敵本体マスを含めず、敵が攻撃できる周囲/射線/警告対象だけを示す。見張り/回転見張りの射線は敵自身のマス内の目元から伸びるレーザーで表示し、敵本体マスは敵マーカーとして表示して、入ると撃破する対象として扱う。
- レイ型などの連続移動で途中マスが敵の危険範囲に入った場合、そのマスへ入った時点でダメージを受ける。その後で敵本体マスを踏めば敵は倒れ、途中で踏み潰した敵の危険範囲は以後消える。
- 移動系の巡回兵と追跡兵は、敵ターン開始時点の見張り/回転見張りレーザー上にいる場合、レーザー上へ移動した場合、または回転見張りの回転後レーザー上にいる場合に消滅する。ダークネスの呪文でレーザーが封じられている間は、この消滅判定も発生しない。
- 凍結の呪文は移動せず1手使い、使用直後から合計3回分の敵ターンを止める。凍結中は危険範囲、着弾予告、次移動プレビューを表示せず、敵の攻撃範囲やメテオ予告に入ってもダメージを受けない。敵本体マーカーは残り、プレイヤーが敵マスを踏めば通常どおり撃破する。
- 障壁の呪文が有効な間も、危険範囲、着弾予告、次移動プレビュー、敵本体マーカーは通常どおり表示する。敵やメテオによるHPダメージは無効化され、既存の1回きり敵/メテオ軽減回数は消費しない。
- ダークネスの呪文が有効な階では、見張りと回転見張りの射線危険を表示せず、その射線上に入ってもダメージを受けない。敵本体マーカー、回転見張りの回転、その他の敵の危険範囲や着弾予告は通常どおり表示する。
- レール破壊の呪文が有効な階では、巡回兵の巡回レールと次移動プレビューを表示せず、敵ターンで巡回兵は移動しない。巡回兵の本体マーカー、隣接危険、隣接/接触ダメージは通常どおり残す。
- 敵同士は同じマスに重ならない。敵ターンでは配列順に移動を解決し、巡回兵は他の敵がいるマス、または同じ敵ターン内で先に予約された移動先へは進まずその場に残る。追跡兵は他の敵がいるマスや予約済みの移動先を一時的な障害物として避け、別経路で近づける場合は1マス進み、到達不能ならその場に残る。
- 巡回兵は巡回路全体を薄い灰色のレールとして常時表示し、現在地から次に進む方向は巡回兵アイコン内の向きで表示する。閉じたループレールは1本のレールとして表示し、巡回兵は最後の点から先頭へ戻って一方向に回る。プレイヤーが巡回兵の現在地からの危険範囲に入った場合は、その敵は進まずに攻撃する。巡回先が見張り系レーザー上なら、その移動後に巡回兵は消滅する。
- 回転見張りは4方向固定で、盤面のレーザーは現在の危険範囲として表示する。プレイヤーが現在のレーザー上にいる場合は回転せずその場で攻撃し、現在のレーザー上にいない場合だけ右回りまたは左回りへ視線方向を切り替えてから、回転後のレーザー上にいるプレイヤーを攻撃する。回転方向は敵アイコンの瞳孔部分にある矢印から読む。回転後レーザー上に巡回兵や追跡兵がいる場合、その移動敵も消滅する。
- 追跡兵はプレイヤーの1手後に最短経路で1マス近づく。通行不可マス、崩落床、盤外、他の敵がいるマス、同じ敵ターン内で先に予約された移動先は避け、別経路で到達可能なら回り込み、到達不能なら動かない。未消費の撒菱と溶岩はできるだけ避け、迂回できる場合は安全な経路を優先する。迂回できずに撒菱または溶岩へ進んだ場合、その追跡兵は倒れて盤面から消える。撒菱へ進んだ場合はその撒菱も消費済みになり安全マスになる。見張り系レーザーは避けず、レーザー上へ移動した場合は消滅する。表示する危険範囲は上下左右1マスで、敵本体マスは敵マーカーとして分ける。次に動くマスへの小さな矢印も常時表示する。プレイヤーが現在地からの危険範囲に入った場合は、追跡せずにその場で攻撃する。
- メテオ兵は移動せず、通行可能な床から制御ランダムに選んだ複数マスを着弾予告マスとして表示する。着弾予告マスは現在の危険範囲とは別扱いで、次の敵ターンにそのマスへいると敵攻撃力ぶんのダメージを受ける。現在地即被弾、通行不可マス、崩落床、敵本体マス、鍵/出口の同時封鎖は避ける。星詠み兵は通常のランダム予告に加えて、行動開始時点のプレイヤー現在地も同じ予告床にする。プレイヤーが移動せず補助カードなどで1手過ごすと被弾し、現在地から離れれば標的予告は回避できる。星詠み兵の予告ダメージはメテオ扱いで、星隠しの布、守護者の大盾、星除けの傘、流星の避雷針、障壁、凍結の対象になる。
- 暗闇フロアでも見張り/回転見張りのレーザー危険マスとメテオ着弾予告マスは視界外まで表示する。凍結中は既存通り危険範囲、着弾予告、次移動プレビューを消し、ダークネスの呪文が有効な階では見張り系レーザー表示も消す。
- `HazardDefinition.damageTrap` は見えている撒菱として扱い、基本移動やカード移動で入った未消費の撒菱マスごとに HP を 1 減らす。カード移動の途中マスも対象になる。踏むと障壁やレリックでダメージを防いだ場合も消費済みになり、そのフロア中は安全マスとして扱う。フライの呪文が有効な間は発動せず、消費済みにもならない。
- `HazardDefinition.hpHalvingTrap` は見えている衰弱罠として扱い、基本移動やカード移動で入ると現在HPをおおむね半分まで下げる罠ダメージを受ける。HP1では減らず、単体ではHP0にならない。障壁や罠ダメージ軽減は通常の罠と同じように効く。
- `HazardDefinition.lavaTile` は見えている溶岩床として扱い、基本移動やカード移動で入った溶岩マスごとに HP を 2 減らす。溶岩上で補助カードなどの移動しない行動を使った場合も、補助効果の解決後に HP を 2 減らしてから敵ターンへ進む。溶岩は発動後も消えず、深層では複数マスの塊として配置されやすくなる。
- 障壁の呪文が有効な間は、撒菱、衰弱罠、溶岩、毒、崩落穴のHPダメージも無効化する。足枷、手札喪失、沼による停止、床破壊、落下先への遷移など、HP減少以外の効果は無効化しない。
- `HazardDefinition.healingTile` は見えている回復マスとして扱い、基本移動やカード移動で初めて入った時に HP を 1 増やして消費する。HP 上限は設けず、カード移動の途中マス、吹き飛ばし経路、ワープ先も対象になる。成長塔中盤以降だけに少量配置する。
- `HazardDefinition.brittleFloor` は初期状態つきの床割れとして扱う。`cracked` は見えているヒビ床で、踏むと崩落床になるが即落下しない。`hiddenWeak` は見た目が通常床の隠し脆い床で、踏むと崩落床になるが即落下しない。`collapsed` は最初から崩れた穴で、入ると HP を 1 減らし、報酬選択や成長ポイント付与を発生させず、短い落下演出の後に開始画面を挟まず前の階の同じマスへ落下する。落下先がクリア済み階の場合は、その階をクリアした瞬間の盤面消費状態を使い、鍵、拾得カード、宝箱、回復マス、敵位置、訪問済み表示、床状態を復元する。落下ダメージ、上階で使った手札、HP、所持遺物、呪い、累計手数と時間は巻き戻さない。落下先がヒビ床または隠し脆い床なら崩落床に変わって停止し、既に崩落床なら連鎖落下する。前の階がない場合は失敗扱いにする。敵の移動、見張り系以外の危険範囲、着弾予告は崩落穴を避けるが、見張り系レーザーは崩落穴を貫通する。
- `TileEffect.swamp` は沼として扱い、レイ型などの連続移動カードで入るとそのマスで止まる。直線2/斜め2のような固定距離カードは途中の沼では止まらず、本来の到達先まで進む。沼の上では移動系カードを使えないが、基本移動と補助カードは通常どおり使える。
- `TileEffect.shackleTrap` は足枷罠として扱う。踏むと次の階まで足枷状態になる。レイ型などの連続移動カードではそのマスで停止するが、直線2/斜め2のような固定距離カードで途中通過した場合は足枷状態を受けつつ本来の到達先まで進む。足枷状態でも基本移動、移動カード、補助カードの手数消費は通常どおり 1 手で、敵ターンだけ最大 2 フェーズ進む。麻痺罠と重なっても敵ターンは 2 フェーズを上限とする。足枷は万能薬で解除できる。
- `TileEffect.poisonTrap` は毒罠として扱う。踏んだ手ではダメージを受けず、移動カードも止まらない。次の成功行動から毒カウントが進み、3 行動ごとに HP を 1 失う。毒ダメージは最大 3 回で、再度踏むと残り回数とカウントを初期値に戻す。毒は万能薬で解除できる。
- `TileEffect.illusionTrap` は幻惑罠として扱う。踏むとその階にいる間、移動カードの正体が `？` 表示になり、移動カードを押すと現在合法に使える移動カードと移動先からランダムに解決する。基本移動と補助カードは通常どおり使え、幻惑は万能薬または次フロア開始で解除される。
- `TileEffect.staggerTrap` は千鳥足罠として扱う。踏むと千鳥足の強制移動を2回分予約し、敵ターン後に1回ずつ、周囲8マスの移動可能なマスからランダムに移動する。千鳥足移動はカードを消費しないが手数を1使い、移動先の罠、拾得、敵ターン、疲労、出口判定は通常の移動と同じように処理する。`千鳥の契約` 所持中に手札が0枚になった時も千鳥足が自動発動し、カードを拾う、クリアする、失敗する、または移動不能になるまで続く。候補が1つもない場合は攻略失敗になる。
- `TileEffect.relicBreakTrap` はレリック破壊罠として扱う。踏むと通常遺物または呪い遺物をランダムに 1 つ破壊し、破壊された遺物は次フロアへ持ち越されない。清めの護符または清めの大護符を持っている場合は、清め系の護符だけが身代わりに壊れて他の遺物と呪いを守る。対象がない場合は何も起きず、移動カードは止まらない。
- `DungeonRules.exitLock` が設定されたフロアでは、指定された鍵マスを踏むまで出口/階段は施錠中として扱う。鍵は階段ロック解除専用で、取得後は床落ちカードと同じように盤面から消える。
- 成長塔と試練塔では `DungeonFloorDefinition.warpTilePairs` から `TileEffect.warp` を自動生成し、2点以上のワープ入口を循環ワープとして扱う。自動生成される同一ワープペアの入口同士は上下左右に直接隣接させず、斜め隣接は許容する。
- 試練塔の生成フロアは、移動不能マスだけで入口から出口までの上下左右経路が詰む盤面を生成しない。入口、出口、鍵、敵、罠、拾得カード、手札拡張、宝箱、通行不可、ワープを重ねない。見張りの初期向きは、盤外や岩/柱ですぐ止まる方向を避け、同じ位置から有効射線が最も長い方向へ寄せる。1-3Fは敵なし、4-5Fは番兵/見張りを最大1体、6-10Fは番兵/見張り/巡回兵を最大2体に抑える。11-15Fは追跡兵を解禁するが1フロア最大1体にし、16F以降はメテオ兵も含めて階数に応じて敵密度を段階的に増やす。1-5Fは拾得カード4枚、6-10Fは5枚を配置する。序盤宝箱は3F/8F固定ではなく、2-4F、5-8F、9-12Fの各ウィンドウから seed で保証階を選び、保証3個のうち少なくとも1個は軽量の怪しい宝箱にする。12F以前のランダム追加宝箱も通常宝箱または軽量の怪しい宝箱に限り、深層の怪しい宝箱は出さない。以後は階数に応じて罠、敵、床割れ、ワープ、暗闇、状態異常床、宝箱を段階的に増やす。31F以降の保証宝箱は敵や拾得カードより先に位置を確保し、51F以降の準備階では宝箱/拾得カードを寄り道として見つけやすくし、圧力階では出口や宝箱周辺に危険配置を寄せる。手札拡張は通常マス上の専用拾得またはクリア報酬候補として出現し、床と報酬で同じ抽選を共有する。未取得なら出現率が次階ごとに2ポイントずつ増え、取得後は2%へ戻る。通常カード枠が9枠に達した後は出現候補から外す。罠・敵・手数制限によってカードを使わないと被弾や疲労が起きやすい階は許容する。
- 吹き飛ばしマスは `TileEffect.blast(direction:)` で上下左右いずれかの固定方向を持つ。踏むと矢印方向へ、盤外または通行不可マスに当たる直前まで移動し、通過したマスは踏破・敵撃破・罠・鍵・出口・拾得カードなど通常移動と同じ処理を行う。
- 手札喪失罠は `TileEffect.discardRandomHand`、`discardAllMoveCards`、`discardAllSupportCards`、`discardAllHands` で表す。踏むと移動後に、ランダム1枠、移動カード全枠、補助カード全枠、または全手札枠を失い、失った枠は即補充しない。塔の所持カード式では対象所持枠の残使用回数を0にする。複数の手札喪失罠を同じ移動で踏んだ場合は、全手札喪失を最優先し、移動カード喪失と補助カード喪失を両方踏んだ場合は両カテゴリを失う。ランダム1枠喪失はカテゴリ全喪失より軽い効果として扱う。

- 呪い遺物「千鳥の契約」を持っている間、基本移動は使えず、基本移動カード枠も表示しない。その代わり通常カード所持枠が1つ増え、既存上限9を超えて最大10枠まで持てる。

## 8. 実装参照マップと更新手順

- ルール全般の実装: `Game/GameCore.swift`・`Game/GameCore+Penalty.swift`。

- 診断メニュー有効時だけ、内部テスターはポーズメニュー、失敗リザルト、クリアリザルトから「この階の初めから」を選べる。これは現在階に入った直後の一時スナップショットへ戻すデバッグ操作で、敵配置、手札、HP、鍵、拾得、床状態、状態異常、タイマーを開始時点へ戻す。通常の区間再挑戦や中断復帰保存の仕様は変えない。

- 遺物 QA は、取得、非重複抽選、候補切れ時の通常宝箱/怪しい宝箱HP補填、ラン内持ち越し、中断復帰、ゲームオーバー時消失、宝箱配置の重なり禁止、各遺物の代表効果、通常遺物発動時のアイコン点滅、怪しい宝箱の2択表示と選択確定、呪い遺物の効果、報酬品質補正、希少度、残り回数、使用済み表示、VoiceOver ラベルを確認する。
