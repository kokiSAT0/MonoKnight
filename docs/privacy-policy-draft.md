# MonoKnight プライバシーポリシー公開原稿

公開前に運営者名、問い合わせ窓口、施行日を確定し、この本文を作者の公開ページに掲載する。公開後のURLをApp Store Connectへ登録する。本ファイルを置くだけではストア用URLの設定は完了しない。

## 保存する情報

MonoKnightは塔の進行、成長、ローカル記録、辞典の発見状況、サウンドなどの設定を端末内に保存します。開発者のサーバーへの自動送信は行いません。アプリを削除すると端末内の保存情報も削除されます。端末のバックアップの取り扱いはAppleの設定に従います。

## 広告

広告の表示にはGoogle AdMobとGoogle User Messaging Platformを使用します。GoogleのSDKはIPアドレス、端末識別子、広告への操作、診断・性能情報などを取り扱う場合があります。端末のトラッキング許可と広告同意の状態に応じて広告を設定します。トラッキングの許可は端末の設定から、広告のプライバシー設定はアプリの設定から確認・変更できます。地域やSDKの状態により表示される選択肢は異なります。

詳しくは[Googleのプライバシーポリシー](https://policies.google.com/privacy?hl=ja)をご確認ください。

## 購入

広告除去の購入・復元はAppleのApp Storeで処理します。開発者は決済カード情報を取得しません。アプリは購入状態を確認し、広告除去へ反映します。

## サウンド

BGMと効果音はアプリに同梱しています。再生にあたりマイクは使用せず、音声を録音・外部送信しません。

## 不具合レポート

不具合レポートはユーザーが共有操作を行った場合に、選択した送信先へ共有されます。共有前に本文を確認してください。レポートにはゲームの状態や再現に必要な情報が含まれる場合があります。

## お問い合わせと更新

運営者名・問い合わせ先・施行日は公開前に作者が確定する必要があります。変更する場合は公開ページ上でお知らせします。
