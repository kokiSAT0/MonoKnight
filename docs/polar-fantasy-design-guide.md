# MonoKnight 極地ファンタジー デザインガイド

本書を、MonoKnight の世界観、キャラクター、画面表現、移動演出、音響、素材管理に関する Source of Truth とする。
盤面・カード・敵行動・塔構成などのゲームルールは `game-rules-handbook.md`、正式リリース範囲は `product-spec.md` を優先する。

## 1. デザイン目標

MonoKnight を「氷の塔を登る、小さな見習いペンギン騎士の冒険」として統一する。

- 可愛さ 70%: 丸い輪郭、少し大きな頭、短い翼、頑張りが伝わる動き
- 騎士らしさ 20%: 氷の兜、青いマフラー、塔へ挑む勇気、節度ある紋章表現
- オーロラの神秘性 10%: 青緑から紫へ移る光、氷面の反射、深層ほど濃くなる夜空
- 情報の読みやすさを装飾より優先し、色覚に依存しない形・線・動きの差を必ず併用する
- 内部 ID、保存キー、入力判定、敵行動、カード効果、塔のゲームルールは変更しない

## 2. 主人公「モノ」

### 2.1 基本設定

- 名前: モノ
- 役割: 氷塔の見習いペンギン騎士
- 目的: 塔の最上階に眠る「暁の氷晶」を灯し、割れ始めた故郷の氷原を守る
- 性格: 真面目で少し不器用。怖くても一歩ずつ進み、失敗すると雪を払って立ち上がる
- 外見: 黒紺の体、白いお腹、橙色のくちばしと足、小さな氷兜、青いマフラー
- シルエット: 盤面を縮小表示しても、丸い胴体、左右の翼、白い腹面で識別できること

### 2.2 表情と演技

- 通常時は進行方向を見て、わずかに胸を張る
- 移動成功時はマフラーと翼が遅れて追従する
- 被ダメージ時は目を閉じ、翼を開き、短く後退する
- 落下時は驚いた表情と広げた翼を見せるが、恐怖を強調しすぎない
- リザルトでは成否にかかわらず、次の挑戦へ向かう前向きさを残す

## 3. 移動演出

UI・演出層では移動を `PlayerMotionStyle` として分類する。ゲームルールの移動解決結果は変更しない。

| 種別 | 主な対象 | 見た目 | 読み取り補助 |
| --- | --- | --- | --- |
| 歩行 `waddle` | 上下左右1マスの基本移動 | 左右へ小さく体を傾けて歩く | 短い足音、移動先だけを明るく縁取る |
| 腹滑り `bellySlide` | レイ型など直線を連続して進む移動 | 体を低くし、氷粒を残して滑る | 直線の雪筋、低い滑走音 |
| 羽ばたき跳躍 `flutterJump` | 中間マスを飛ばす2マス移動、ナイト型 | 翼を懸命に羽ばたかせ、弧を描いて着地する | 影の縮小、着地時の雪輪、羽音 |
| ワープ `warp` | ワープ床・ワープ解決 | オーロラ色の輪へ縮小して消え、出口側で復元する | 六角形の輪と上向き粒子、専用音 |
| 落下 `fall` | 崩落穴・階下への落下 | 氷片とともに縮小し、翼を広げて下層へ落ちる | 黒い穴、下向き三角、低い落下音 |
| 強制滑走 `forcedSlide` | 吹き飛ばしなどの強制移動 | 姿勢を崩して横滑りする | 破線の軌跡、短い風切り音 |

- 1区間の基本時間は従来どおり 150ms から 250ms を目安にする
- 「視差を減らす」が有効な時は跳躍の拡大縮小、回転、粒子量を抑え、位置遷移だけで意味を維持する
- 連続経路はマスごとの解決順を保ち、途中停止・出口到達・被ダメージのタイミングを変えない

## 4. 塔と敵の割り当て

### 4.1 塔

- 基礎塔: 朝の氷原。明るい水色と柔らかな雪で、モノの訓練場所として描く
- 成長塔: 夕暮れから夜へ移るオーロラ塔。10Fごとに青、青緑、紫、濃紺を深める
- 試練塔: 吹雪の裂け目。高コントラストの氷と夜空で、生成階でも危険情報を最優先する
- ひび床は「氷の亀裂」、崩落穴は「割れて下階が見える穴」として、階下へ落ちるルールを世界観と一致させる

### 4.2 敵表示

内部型と行動は維持し、表示名・シルエット・演出を次の極地生物へ割り当てる。

| 内部の役割 | 表示テーマ | 読み取りの要点 |
| --- | --- | --- |
| 番兵 | 氷鎧のアザラシ | 丸い体と正面の盾形。固定範囲を守る |
| 巡回兵 | 氷路のセイウチ | 牙と太い体。レール方向を牙の向きで示す |
| 見張り | シロフクロウ | 大きな目と直線の視線。固定射線を監視する |
| 回転見張り | オーロラフクロウ | 翼の円弧と回転矢印。射線の回転を予告する |
| 追跡兵 | ホッキョクギツネ | 尖った耳と尾。モノを追う向きを姿勢で示す |
| メテオ兵 | 氷下のシャチ | 氷下の影と背びれ。次の危険マスを円環で予告する |
| 星詠み兵 | オーロラシャチ | 二重の影と発光する背びれ。より強い予告を二重線で示す |

- 「メテオ兵」「星詠み兵」などの内部型・内部IDは互換性のため維持する
- 攻撃の意味は変えず、落下物表現を「氷下から迫るシャチの突き上げ」に置き換える
- シャチ本体を常時盤上へ置かず、氷下の影、背びれ、波紋で予告する。危険確定時だけ氷片と白い水しぶきを加える

## 5. 盤面記号とアクセシビリティ

色と形を必ず組み合わせ、グレースケールでも区別できるようにする。

| 要素 | 色 | 形・パターン | 動き |
| --- | --- | --- | --- |
| 移動可能枠 | オーロラ青緑 | 四隅だけの角括弧 | ゆっくり明滅 |
| 移動途中マス | 淡い水色 | 中央へ向かう短い雪筋 | 進行方向へ流れる |
| ひび床 | 警告水色＋白 | 中央から伸びる3本以上の亀裂 | 初回踏破後に短く震える |
| 崩落穴 | 濃紺＋黒 | 不規則な穴と下向き三角 | 氷片が内側へ落ちる |
| シャチ予告 | 紫＋赤紫 | 楕円の影、背びれ、単線または二重線 | 水面下を周回する |
| ワープ | 紫＋青緑 | 六角形の二重輪 | 内外で逆回転する |

- VoiceOver は「見た目の生物名＋行動」を読み上げる。例: 「氷下のシャチ、次の手でこのマスを攻撃」
- 色名だけを説明に使わず、「亀裂」「穴」「背びれ」「六角形」などの形状語を含める
- タップ領域 44pt 以上、文字と重要記号のコントラストは WCAG AA 相当を目安にする

## 6. UI方針

- タイトル: 夜明け前の氷原、オーロラ、中央のモノ。ロゴと開始操作を最優先する
- 塔選択: 各塔を氷柱状のカードとして描き、難度、到達階、開始位置を同じ階層で比較できるようにする
- HUD: 氷板を模した半透明パネルを使い、HP、階数、手数、状態異常の可読性を装飾より優先する
- リザルト: 登頂時は暁の光、失敗時は薄明の雪原を使う。主要結果、再挑戦、塔へ戻る操作を上から順に配置する
- アプリアイコンと起動マークは、同じモノの顔、氷兜、青いマフラー、オーロラ背景を用いる
- 小さな画面では背景装飾を減らし、iPad Portraitでは盤面とカードの視線距離が広がりすぎない最大幅を設ける

## 7. 響きの設計

### 7.1 BGM

- タイトル: 透明なベルと柔らかなパッド。期待感は出すが勇壮にしすぎない
- 塔: 氷を打つ軽い音、低い風、短い旋律。盤面を考える邪魔にならない反復にする
- 深層: 低域と風を少し増やし、音量差ではなく音色で緊張を作る
- ループ継ぎ目を聞き取りにくくし、モノラル再生でも主要旋律が消えない構成にする

### 7.2 SE

- 歩行、腹滑り、羽ばたき、着地、ワープ、落下を聞き分けられるようにする
- 決定、無効操作、カード取得、宝箱、被ダメージ、回復、階段解放、シャチ予告を短い音で区別する
- 危険通知はBGMより明瞭にするが、連続再生時に耳障りにならない音量と長さに抑える
- BGMとSEは個別ミュート・個別音量を提供する
- 広告表示、アプリのバックグラウンド移行、音声割り込み時は停止し、復帰時は設定に従って再開する
- 端末のサイレント設定と他アプリの音声を尊重し、過度な音圧や突然の大音量を避ける

## 8. 素材と利用許諾

- 画像・音声・フォントは、自作または利用条件を確認した生成素材だけを採用する
- 外部の既存キャラクター、ロゴ、効果音、楽曲を模倣または転用しない
- 追加素材ごとに次をDraft PRの「素材ライセンス」へ記録する
  - ファイルパス
  - 制作者または生成手段
  - 作成日
  - 元プロンプトまたは制作手順
  - 利用条件、帰属表示の要否、改変可否
- 生成素材は人が最終確認し、第三者の商標・著作物に類似しないこと、ゲーム内で意味を誤認させないことを確認する
- 使わなかった候補素材はリポジトリへ含めない

## 9. 実装上の互換性

- 敵・カード・塔の内部ID、`UserDefaults`キー、保存JSONのキーと意味を維持する
- 既存の `EnemyPresentationKind` とゲームルール上の敵型は維持し、表示名、描画、アクセシビリティ文言、音だけを差し替える
- `Game` Swift Package は移動解決と公開プレゼンテーション情報を担当し、SwiftUI、SpriteKit、音響サービスの責務境界を崩さない
- ゲームルール変更が必要になった場合は、実装と `game-rules-handbook.md` を同じコミットで更新する

## 10. 受け入れ基準

- タイトル、塔選択、盤面、リザルトで同じモノと極地配色が認識できる
- 歩行、腹滑り、羽ばたき跳躍、ワープ、落下が動きと音の両方で区別できる
- ひび床、崩落穴、シャチ予告、ワープ、移動枠が色なしでも形で区別できる
- BGMとSEを個別にミュート・音量変更でき、バックグラウンドと広告表示で安全に停止復帰する
- iPhone 16 / iOS 18.6 と iPad Portrait で主要4画面が崩れず、VoiceOverラベルが世界観と行動を正しく伝える
- UI変更ごとのスクリーンショットまたは短い動画と、素材の制作・利用条件がDraft PRへ記録されている
