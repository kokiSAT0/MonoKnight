# ストア提出用原稿と残項目

## 商品ページ

アプリ名: MonoKnight

サブタイトル: カードで騎士を導く塔パズル

プロモーション文: カードの使いどころを読み、敵と床の仕掛けを越えて塔の出口へ。基礎塔で覚え、成長塔で鍛え、試練塔で自分の限界に挑もう。

### 説明文

一手を考え、騎士を塔の出口へ導こう。

MonoKnightは、カードの移動と盤面の仕掛けを組み合わせて攻略する塔パズルです。残りHP、手数、カードの使用回数を見ながら、安全な道を探すか、報酬を求めて寄り道するかを選びます。

- 基礎塔で移動や仕掛けを覚える
- 成長塔で50階に挑み、成長を積み重ねる
- 試練塔で手持ちのカードを活かした攻略に挑む
- 発見したカード・敵・仕掛けを辞典で確認する
- 中断した塔へ「続きから」戻る
- BGMと効果音の音量をそれぞれ調整する

白・黒・グレーを基調とした盤面と、専用に生成したサウンドで一手ずつ考える時間を楽しめます。

広告を含みます。アプリ内購入で広告を非表示にできます。

キーワード: パズル,カード,騎士,ダンジョン,ローグライク,塔,戦略,ボード

## TestFlight

ベータ版説明: カードで騎士を導く塔パズルです。基礎塔、成長塔、試練塔の進行と、BGM・効果音を組み込んだ提出準備版を確認してください。

テストしてほしい内容:

1. 初回同意、塔の開始、中断再開、クリア・敗北後の戻り方。
2. タイトルと各塔のBGM、移動・取得・ダメージ・回復・結果の効果音。
3. 音量の保存、消音、ポーズ、着信、画面ロック、ヘッドホン抜去後の停止・再開。
4. 広告中にゲームの音が鳴らないこと、広告終了後にポーズ状態を維持すること。
5. 広告除去の購入と復元、同意の再設定、iPhone/iPadの縦画面表示。

フィードバック用メール: 作者から確定情報を受け取って入力する。

## 審査担当者への説明

ログインは不要です。タイトルから塔を選び、基礎塔の1Fを開始してください。カードを選び、移動先をタップして騎士を出口へ導きます。設定でサウンドを調整し、「プライバシーについて」でデータの取り扱いを確認できます。広告除去の購入と復元は設定から行えます。

## 公開前に必要な確定情報・操作

- サポート用メール、公開サポートページ、公開プライバシーポリシーURLを `release-metadata.json` とApp Store Connectに入力する。
- `GAD_INTERSTITIAL_UNIT_ID` を作者の本番ユニットに設定する。リワード広告は `GADRewardedAdUnitID` が未設定なら現行実装で無効なため、有効化する場合のみ本番IDとInfo.plist設定を追加する。ダミーのIDを作らない。
- Apple Developerチーム `5TAKV37ZM4` の配布署名・プロビジョニングと、Bundle ID `com.kokisato.MonoKnightApp` のApp Store Connect登録を確認する。
- `remove_ads_mk` の商品、販売契約、価格、購入・復元をSandbox/TestFlightで確認する。
- SDKを含むプライバシー申告、年齢区分、配信地域、価格、輸出に関する回答を作者の実情報で確定する。
- 実機のiPhone/iPadで通しプレイ、音の割り込み、広告・同意・購入を確認する。シミュレーターのテスト結果で代用しない。
- 商品ページ用の対応サイズのスクリーンショットを用意する。検証用添付画像は実際の画面記録だが、提出用サイズ・画面構成を満たす確認は別途必要。

`python3 Scripts/check-release-assets.py --app /path/to/MonoKnightApp.app --strict` は、公開URL・連絡先・広告設定が未確定の状態を合格として扱わない。これらを確定した後に、署名済みArchiveとApp Store Connectの最終確認を行う。
