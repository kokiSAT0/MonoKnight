# MonoKnight 音響素材台帳

## 生成方法と権利

`MonoKnightApp/Audio`のWAVファイルは、2026年8月13日に
`Scripts/generate-polar-audio.py`で生成したMonoKnight専用のオリジナル素材です。
外部の音源、サンプル、楽曲、効果音、生成AIサービスは使用していません。

- 権利者: MonoKnightプロジェクト
- 用途: MonoKnightアプリ内での利用
- クレジット表記: 不要
- 加工: 可
- 再生成: `python3 Scripts/generate-polar-audio.py`

## ファイル構成

- `bgm_title.wav`: タイトル／リザルト向けのオーロラ調ループ
- `bgm_tower.wav`: 通常の氷塔向けループ
- `bgm_deep_tower.wav`: 深層向けの低音ループ
- `se_*.wav`: 歩行、腹滑り、羽ばたき、ワープ、落下、被弾、取得、シャチ予告、決定、無効操作、回復の各効果音
