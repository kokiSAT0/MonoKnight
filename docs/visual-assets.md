# MonoKnight ビジュアル素材台帳

## モノのアプリアイコン／起動マーク

- 作成日: 2026年8月13日
- 作成方法: OpenAIの画像生成機能でMonoKnight専用に生成
- 外部素材: 不使用
- 用途: `AppIcon.appiconset`と`LaunchMark.imageset`
- 加工: 生成原画を`1024 x 1024`と`512 x 512`へリサイズ
- クレジット表記: 不要

生成指示では、氷の兜、オーロラの宝石、水色のマフラーを着けた見習いペンギン騎士「モノ」を指定しました。
文字、ロゴ、透かし、既存キャラクターを含めず、可愛さ70%、騎士らしさ20%、オーロラの神秘性10%の比率を反映しています。

同じ原画を通常／ダーク／ティンテッドのアプリアイコンと、ライト／ダークの起動マークへ適用し、起動前後でキャラクターの見た目が変わらないようにしています。
